# Guides

Guides walk you through building something with Super from start to finish. Where the
other pages explain one part of Super each, a guide shows the parts working together.

| Guide | What you build |
| --- | --- |
| [Build a tower defense](tower-defense.md) | Outpost, a small tower defense with waves, towers, gold, lives and a title screen, made from built-in shapes |
| [Build a 3D platformer](platformer.md) | Skylark, a small platformer with a bird you steer, a camera that follows, physics, lifts, a crate to push and two levels |

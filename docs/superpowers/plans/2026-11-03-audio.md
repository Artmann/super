# Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Super plays music, layered ambience, flat and world one-shots, and looping sounds on entities, all mixed in C# and testable with no sound card.

**Architecture:** `Content` decodes clips (`SoundRef`) and reads `.ambience.json` (`AmbienceRef`). The `Audio` service turns game calls into commands for a `Mixer`. The mixer owns every voice, fade, pan and channel gain, and writes 48 kHz stereo floats. The mixer is driven one of two ways. With a device, an OpenAL thread pulls it in real time. Everywhere else (headless, screenshots, recordings, a machine with no device), the game loop advances it by one tick of samples per tick, which makes it exact and repeatable. `Super.Ecs` adds `Sound` and `Ambience` components and a draw hook that compares them against the previous frame and sends commands.

**Tech Stack:** .NET 10, C#, xunit 2.9, Silk.NET.OpenAL 2.23.0 + Silk.NET.OpenAL.Soft.Native 2.23.0, NVorbis (OGG), NLayer (MP3), ffmpeg (already used by recording).

**Spec:** `docs/superpowers/specs/2026-11-03-audio-design.md`

## Global Constraints

- Channels: `Master`, `Music`, `Ambience`, `Effects`, `Interface`, each volume 0–1, Master scales the rest.
- Default channels: `audio.Music` → Music; `Ambience` → Ambience; flat `audio.Play` → Interface; placed `audio.Play` and `Sound` → Effects. Every call takes an optional `channel:` override.
- Mixer output: 48 000 Hz, stereo, float.
- World falloff: full volume within `near` (default 2 m), silent beyond `far` (default 50 m). Equal-power panning from the camera's facing. Stereo clips placed in the world are folded to mono.
- `Scale` 0 pauses world sounds and `Sound` components. Below 1 they play slower and lower. Music, ambience and interface ignore `Scale`.
- Music cross-fades over 2 s by default (`fadeSeconds:`). Same track again → nothing. `Music(null)` → fades out.
- Audio randomness never touches the game's `GameRandom`. Headless, screenshots, recordings and tests use a fixed audio seed. Live play uses an unseeded one.
- The game thread never waits on the audio thread. The one exception is the hand-over when recording starts or stops (Task 8).
- A running game allocates nothing for audio once warmed up. Starting a streamed clip (music) may allocate its decoder.
- Formats: `.wav` (16-bit and 32-bit float PCM, mono or stereo), `.ogg`, `.mp3`. Anything else → `ContentException` naming the path.
- Do not use the Pixabay files or Warcraft clips from Downloads. Copy only the Ninja Adventure (CC0) files the example uses.
- Repo rules (CLAUDE.md): braces on every control statement; docs updated in the same commit as the code; conventional commits; no Claude author or Co-Authored-By lines; every test must be proven to fail by breaking the code first; time-based tests use the mixer's sample clock, never sleeps; rebuild, never `--no-build`.

## Review Focus

1. **A `Sound` entity destroyed, then its ID reused in the same frame.** The old voice must fade out and a new one start. Key on `Entity` (id + generation), not id. Test in Task 6.
2. **A clip whose sample rate isn't 48 kHz (most Ninja Adventure WAVs are 44.1 kHz).** It must play at the right pitch and length. Test in Task 1/3.
3. **More voices than the limit (e.g. a machine gun).** The quietest voice drops and music is never dropped. Nothing throws. Test in Task 3.
4. **`Scale = 0` while a placed one-shot plays, then back to 1.** The one-shot resumes where it was, while music kept going. Test in Task 5.
5. **No sound device or OpenAL fails to open.** The game runs silently and audio still advances per tick, so voices don't pile up. Test in Task 7 by forcing the open to fail.

### Task 3: The mixer

**Files:**
- Create: `src/Super/Audio/Mixer.cs`, `Voice.cs`, `Spatial.cs`, `PlayingSound.cs`
- Test: `tests/Super.Tests/Audio/MixerTests.cs`, `SpatialTests.cs`

**Interfaces:**
- Consumes: `SoundClip`, `ISampleReader`, `Channel`.
- Produces:
  - `internal static class Spatial { static float Falloff(float distance, float near, float far); static float Pan(Vector3 listener, Vector3 forward, Vector3 source); static (float Left, float Right) EqualPower(float pan); }`.
    `Falloff`: 1 for d ≤ near, 0 for d ≥ far, else `(near/d - near/far) / (1 - near/far)`. `Pan` is the dot of the direction to the source with `right = normalize(cross(forward, UnitY))`, −1..1, and 0 at the listener. `EqualPower`: `left = cos((pan+1)·π/4)`, `right = sin((pan+1)·π/4)`.
  - `internal sealed class Mixer` with `const int SampleRate = 48000`, `const int MaxVoices = 64`, and:
    - `int Start(in VoiceStart start)` → voice id. `VoiceStart { SoundClip Clip; Channel Channel; float Volume; bool Loop; float Pitch; Vector3? Position; float Near; float Far; float FadeInSeconds; bool FollowsScale; bool IsMusic; }`
    - `void Stop(int voice, float fadeSeconds)`, `void SetVolume(int voice, float volume, float fadeSeconds)`, `void SetPosition(int voice, Vector3 position)`
    - `void SetChannelVolume(Channel channel, float volume)`, `void SetListener(Vector3 position, Vector3 forward)`, `void SetWorldRate(float scale)`
    - `void Mix(Span<float> stereo)`. It fills `stereo.Length / 2` frames and moves the sample clock on.
    - `int Snapshot(Span<PlayingSound> into)` → count.
  - `public readonly record struct PlayingSound(string Clip, Channel Channel, bool Looping, float Gain, float Pan, double Seconds)`. `Gain` = voice volume × fade × falloff × channel × master. `Clip` is the content path. `Seconds` is how far into the clip it is.
  - Voices step through the source at `clip.SampleRate / 48000 × pitch × (FollowsScale ? worldRate : 1)`, reading with linear interpolation. Placed voices fold stereo to mono before panning. Flat voices keep their stereo.
  - Starting past `MaxVoices` drops the quietest non-music voice. If the new voice would be the quietest, it's dropped instead.
  - A voice that ends (not looping) is removed. A voice that fades to 0 because of `Stop` is removed.
